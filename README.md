# CYPRUS REALTOR LAB

Демонстрационный лендинг тренинга для риелторов на Кипре. Полностью статический и готов к бесплатному размещению на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub и загрузите в него все файлы из этой папки.
2. Откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

GitHub опубликует страницу по адресу `https://USERNAME.github.io/REPOSITORY/`.

## Перед реальным запуском

В `script.js` замените значение `WHATSAPP_NUMBER` на настоящий номер в международном формате без плюса и пробелов. Контент, персонажи, даты, отзывы и результаты на странице вымышлены и предназначены для демонстрации дизайна.
